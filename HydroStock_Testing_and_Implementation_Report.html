1. Project Implementation Summary

HydroStock is a role-based web application for hydroelectric plant stores, procurement, billing, supplier coordination, and plant equipment maintenance. The application uses Java Servlets for request handling, JSP views for presentation, JDBC DAOs for database access, MySQL for persistence, and Tomcat for deployment.

LayerImplementation
PresentationJSP pages, Bootstrap 5 responsive layout, Font Awesome icons, Chart.js analytics, shared header/sidebar/footer.
ControllerServlet routes for authentication, administration, materials, stock, purchase orders, billing, reports, equipment, and supplier portal.
Data accessJDBC DAOs using prepared statements, transactional stock operations, KPI aggregate queries, and supplier/order/invoice joins.
SecuritySession authentication and role authorization for ADMIN, INVENTORY_MANAGER, PURCHASE_MANAGER, SUPPLIER, and PLANT_ENGINEER.
DatabaseMySQL tables for users, roles, categories, materials, suppliers, equipment, maintenance, stock transactions, purchase orders, invoices, payments, and notifications.

2. Deployment and Startup Steps

  1. Start XAMPP MySQL and Tomcat services.
  2. Import database/database.sql into MySQL database hydrostock_db.
  3. Open the project folder in VS Code.
  4. Run build_and_deploy.bat.
  5. The script compiles Java files using Tomcat Servlet/JSP APIs and bundled MySQL/JSTL libraries.
  6. The script synchronizes the exploded web application into C:\xampp\tomcat\webapps\HydroStock.
  7. The script packages the current webapp into HydroStock.war so Tomcat also reloads the current JSP bundle.
  8. Open http://localhost:8080/HydroStock.
